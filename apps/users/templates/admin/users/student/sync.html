Full, hostel and picture modes match by trimmed, case-insensitive email. CSV must use UTF-8. XLSX identifiers should be stored as text to preserve leading zeros.

Full sync accepts email, registration_number, name, hostel, room_number, gender, contact_number, parent_contact, year, picture, student_type (HOSTELLER or DAY_SCHOLAR). New students require registration_number and name. FULL sync cannot change existing registration numbers. Absent columns are preserved; blank optional values clear fields, except pictures which are preserved by default.

Hostel mode requires email,hostel,room_number. Picture mode requires email,picture. Columns outside the selected mode are ignored and listed in Preview. Hostel names must match exactly. Unknown students in these two modes are errors. Any validation error blocks the entire file.

Picture headers accepted (case-insensitive): picture, URL, picture_url, image_url. Supply only one picture column.

IDENTITY UPDATE (superusers only) requires user,registration_number,email. user is the existing CustomUser ID. Both identity fields must be nonblank. This mode corrects existing students in place and preserves history; it never creates students or users.
